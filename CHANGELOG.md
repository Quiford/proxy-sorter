# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-04-17

### Added

- New reusable `proxysorter` package modules (parser, checker, models, IO helpers)
- Concurrent proxy scanner engine with result summaries
- CLI tool with `fix` and `check` commands
- Upgraded GUI fixer and checker apps
- Telegram contact integration (`@Quiford`) in tools and docs
- Open-source project standards:
  - README
  - MIT LICENSE
  - CONTRIBUTING, CODE_OF_CONDUCT, SECURITY
  - GitHub issue and pull request templates
  - CI workflow
  - Tests
