# Security Policy

## Supported versions

This project currently supports the latest commit on the `main` branch.

## Reporting a vulnerability

Please do not post vulnerabilities publicly first.

1. Send a private report with reproduction steps and impact details.
2. You can contact the maintainer on Telegram: **[@Quiford](https://t.me/Quiford)**.
3. Include proof-of-concept details and affected files/features.

We will acknowledge reports as soon as possible and work toward a fix.

## Responsible use

This tool is for legal and authorized testing only.  
Using this project for unauthorized access or abuse is prohibited.
