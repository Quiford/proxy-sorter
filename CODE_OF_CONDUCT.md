# Code of Conduct

## Our standards

This project is committed to a welcoming and harassment-free community for everyone.

Examples of positive behavior:

- Being respectful and constructive
- Accepting feedback gracefully
- Helping new contributors learn

Examples of unacceptable behavior:

- Harassment or discrimination
- Personal attacks or threats
- Sharing private information without consent

## Enforcement

Project maintainers may remove comments, issues, or contributions that violate this code of conduct.

For serious concerns, contact the maintainer on Telegram: **[@Quiford](https://t.me/Quiford)**.
